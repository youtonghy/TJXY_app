# 移动端功能验收

测试环境：Android Pixel 10 Pro 模拟器（arm64）、release APK、云服务器。
禁止使用本地后端代替云端验证。需要登录的项目必须使用真实授权会话。

| 功能 | 操作与验收条件 | 本次状态 |
| --- | --- | --- |
| 冷启动 | 强制停止后启动；显示应用或登录界面，无白屏、崩溃 | 已通过 |
| 登录路由 | 未登录进入首页；跳转登录页，无重定向循环 | 实机及回归测试通过 |
| 服务器连接 | 保存 HTTPS 云服务器；加载公开信息与品牌图片 | 已通过 |
| 登录界面 | 竖屏查看、键盘输入、切换密码显示；无横向溢出 | 竖屏布局已通过，其余待验收 |
| 错误登录 | 输入错误密码；显示错误并能再次提交 | 待登录验证 |
| 密码登录 | 授权账号登录；进入首页，内容正确加载 | 待登录验证 |
| 二维码登录 | 生成二维码、批准、超时后重试 | 待登录验证 |
| 记住登录 | 勾选后登录；强停重启仍登录；退出后重启不恢复 | 安全存储实现完成，待实机验收 |
| 首页与图片 | 轮播、列表、图片加载、刷新、空状态 | 待登录验证 |
| 媒体库 | 进入媒体库、分类筛选、翻页、返回 | 待登录验证 |
| 搜索 | 输入、清空、无结果、打开搜索结果 | 待登录验证 |
| 详情 | 海报、信息、剧集、收藏及返回 | 待登录验证 |

| AI | 会话列表、发送、响应、取消、错误恢复 | 待登录验证 |

| 系统返回键 | 详情回列表，列表回首页；播放退出回详情 | 待登录验证 |
| 网络故障 | 断网及恢复；错误可见，可重试且无白屏 | 待验收 |
| 生命周期 | 后台恢复、旋转、低内存重建、升级安装保留状态 | 待验收 |
